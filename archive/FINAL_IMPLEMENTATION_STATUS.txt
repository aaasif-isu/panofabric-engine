File: panoengine/decentralized/mla.py (92 LOC)

✓ MLA = Momentum Look-Ahead (SIMPLE MOMENTUM, NO DIRECTION CORRECTION)

✓ Update Rule:
  m  ← γ·m + (1−γ)·Δ              (momentum accumulation)
  θ  ← θ − lr·(γ·m_new + Δ)        (parameter update with lookahead)

✓ Hyperparameters: ONLY 2
  - lr (learning rate)
  - momentum (γ coefficient)

✓ Key Points:
  ✓ Base MLA, not SmartDCMLA_v2 (direction correction is separate)
  ✓ Server-side only
  ✓ Worker look-ahead dispatch (θ − lr·γ·m) is HeLoCo, not MLA
  ✓ Clean, minimal implementation
